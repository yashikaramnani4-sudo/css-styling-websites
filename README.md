#Styled Portfolio Website


## 📌 Project Description
A responsive portfolio website created using HTML5 and CSS3.
The project demonstrates modern UI styling techniques including Flexbox, CSS Grid, hover effects, responsive design, custom fonts, and animations.


---


## 🚀 Features


- Responsive Design
- External CSS Styling
- CSS Grid Layout
- Flexbox Navigation
- Hover Effects & Animations
- Google Fonts Integration
- Contact Form Styling
- Mobile-Friendly Interface
